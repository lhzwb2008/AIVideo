# Coze 工作流整体改造 Prompt（复制整段到 code.coze.cn 项目 AI）

---

请重构当前「AI 资讯竖屏短视频」工作流的**整体架构**，不是只改某一个节点。

## 背景：职责拆分

原先：Coze 负责「生图 + TTS 配音 + ffmpeg 视频合成」全流程。
现在：**生图已迁到本地 API（AiHubMix gpt-image-2）**，Coze 只负责：

1. 解析输入 JSON 脚本
2. 按页下载外部已生成配图（`image_url`）
3. 按页 TTS（`narration`）
4. 按页 ffmpeg 合成竖屏片段（背景图 + 上屏文字）
5. 拼接 5 段为最终 60 秒 MP4，返回可下载 URL

**请删除或 bypass 工作流内所有「根据 image_prompt 调用生图模型」的逻辑。** `image_prompt` 仅作调试/兜底，正常路径不应再触发生图 API。

---

## 输入契约

工作流入口参数名：`input`（字符串，内容是 JSON）。

解析后结构：

```json
{
  "title": "OpenAI要上市了",
  "keyword": "OpenAI",
  "source": { "title": "...", "url": "https://...", "site": "CNBC" },
  "slides": [ /* 恰好 5 页 */ ]
}
```

每页 `slide` 字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| layout | ✓ | cover / insight / data / story / outro |
| headline | ✓ | 上屏大标题（中文） |
| narration | ✓ | TTS 口播原文，原样朗读，不改写 |
| image_url | ✓（新流程） | 公网 PNG/JPEG，本地 API 已生成并上传（如 catbox） |
| image_b64 | 可选 | 无 image_url 时的兜底（base64 PNG） |
| image_prompt | 可选 | **不再用于生图**，仅兜底或日志 |
| subtitle | cover 专用 | 封面副标题 |
| stat | data 专用 | 中央超大数字/短语 |
| bullets | 部分页 | `[{"title":"...","desc":"..."}]` |

**正常生产路径：每页必有 `image_url`。** 本地流水线保证 5 页都已配图后再调用 Coze。

---

## 整体流程（请按此重组工作流）

```
START
  ↓
[1] 解析 input JSON → script 对象，校验 slides.length == 5
  ↓
[2] FOR i in 0..4：准备素材（可并行）
      ├─ 取 slide.image_url
      ├─ 若无 url 但有 image_b64 → 解码写本地 /tmp/slide_{i}.png
      ├─ 若无 url/b64 但有 image_prompt → 【仅兜底】内部生图（默认应关闭或告警）
      ├─ 下载/写入后校验文件存在且 size > 0
      └─ 输出 local_image_path[i]
  ↓
[3] FOR i in 0..4：TTS（可并行）
      ├─ 输入：slide.narration（禁止改写、禁止加标点以外的内容）
      ├─ 输出：local_audio_path[i]（mp3/wav）
      └─ 记录 duration[i]
  ↓
[4] FOR i in 0..4：单页视频片段（video_clip_node）
      ├─ 输入：local_image_path[i], local_audio_path[i], slide 文案字段
      ├─ 画布：竖屏 1080×1920（9:16）
      ├─ 背景：image 等比裁剪/铺满，不变形
      ├─ 前景：按 layout 渲染中文文字（drawtext 或等价方案）
      │     cover  → 超大 headline + subtitle，无 bullets
      │     insight → headline + 2 条 bullets
      │     data   → 中央 stat + headline + bullets
      │     story  → headline + 2-3 bullets
      │     outro  → headline + 0-2 bullets/标签
      ├─ 时长：以音频 duration[i] 为准（视频跟音频对齐）
      └─ 输出：clip_path[i]（mp4）
  ↓
[5] 拼接 5 段 clip → final.mp4（无转场或简单硬切均可）
  ↓
[6] 上传 final.mp4 → 返回 {"output": "<公网可下载 mp4 url>"}

END
```

---

## 各 layout 上屏规则（与原先保持一致）

- **cover**：headline 8–14 字超大居中/偏上；subtitle 10–16 字；不要 bullets；不要「头条」等小标签
- **insight**：headline 中等；2 条 bullet（title 为主，desc 次要）
- **data**：中央 `stat` 超大（如「8500亿美元」）；headline + 1–2 bullets
- **story**：headline + 2–3 bullets（时间线/要点）
- **outro**：headline + 可选 hashtag bullet（如 #OpenAI）

字体：中文字体必须可用（ffmpeg drawtext 指定 fontfile，或项目内嵌字体路径）。避免中文乱码/方块。

## 图片获取逻辑（核心改动）

实现函数 `resolve_slide_image(slide, index) -> local_path`：

```python
def resolve_slide_image(slide, index, work_dir):
    # 优先级 1：公网 URL（主路径）
    if slide.get("image_url"):
        path = download(slide["image_url"], f"{work_dir}/slide_{index:02d}.png")
        return path

    # 优先级 2：base64（备用）
    if slide.get("image_b64"):
        path = decode_b64(slide["image_b64"], f"{work_dir}/slide_{index:02d}.png")
        return path

    # 优先级 3：兜底生图（可选，默认关闭）
    if ALLOW_LEGACY_IMAGE_GEN and slide.get("image_prompt"):
        return legacy_generate(slide["image_prompt"], ...)

    raise ValueError(f"slide {index} 缺少 image_url，无法合成")
```

下载要求：
- timeout ≥ 60s，失败重试 2 次
- 支持 https://files.catbox.moe/ 等公网图床
- 下载后验证 Content-Type 为 image 且文件可读

---

## TTS 要求

- 输入：`slide.narration` 逐字朗读
- 语言：中文普通话
- 语速：资讯口播风格，略快于新闻播报
- 禁止：改写文案、添加「欢迎收看」等套话
- 每页独立生成音频，供 video_clip 对齐

---

## video_clip / ffmpeg 要求

- 修复并保留 `graphs/nodes/video_clip_node.py`（或等价节点）
- 每段输出 1080×1920 h264 + aac
- 音频轨来自 TTS；视频时长 = 音频时长
- 背景图来自 `resolve_slide_image`，**不要**再调用生图
- 错误信息需包含：页码、layout、缺失的文件路径、ffmpeg stderr 末 500 字符

---

## 输出契约

工作流最终返回 JSON，本地脚本从 `output` 字段取 MP4 URL 下载：

```json
{
  "output": "https://....../final.mp4"
}
```

保持与现有部署 API 兼容（/run/stream 流式接口，合成约 5–8 分钟）。

- 删除：批量「读取 image_prompt → 调用 Coze/内置生图模型」的主路径

## 自测用例

用以下 input 做端到端试跑（1 页简化版或完整 5 页均可）：

```json
{
  "title": "GPT Image 2 测试",
  "keyword": "AI",
  "source": {"title": "test", "url": "https://example.com", "site": "test"},
  "slides": [
    {
      "layout": "cover",
      "headline": "AI 生图测试",
      "subtitle": "竖屏封面",
      "bullets": [],
      "narration": "这是一条测试口播。",
      "image_url": "https://files.catbox.moe/m2i0jx.png",
      "image_prompt": "（忽略，不应触发生图）"
    }
  ]
}
```

通过标准：
1. 不调用任何生图 API
2. 成功下载 image_url 并用于背景
3. TTS 朗读 narration
4. 输出含中文字幕/标题的竖屏 mp4
5. 返回有效 output URL
